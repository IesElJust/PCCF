# 7. Recursos

Els recursos didàctics comprenen aquells elements, eines o materials que utilitzarem per facilitar el procés formatiu. En el present mòdul, disposarem de:

* **Recursos materials**:
    * Documentació elaborada pel professorat sobre Windows Server, dominis, usuaris, grups, permisos i recursos compartits.
    * Guies de pràctiques i rúbriques de seguiment.
    * Documentació oficial de Microsoft i manuals de referència sobre administració de sistemes.

* **Recursos tecnològics**:
    * Ordinadors amb connexió a internet i capacitat suficient per executar màquines virtuals.
    * Programari de virtualització.
    * Imatges ISO de sistemes operatius de servidor i client.
    * Ferramentes d'administració de Windows Server, Active Directory, monitorització i PowerShell.
    * Aula virtual per al lliurament d'activitats, documentació i retroalimentació.

* **Recursos organitzatius**:
    * Treball individual per consolidar procediments d'administració.
    * Treball cooperatiu per comprovar accessos, recursos compartits i escenaris d'integració.
    * Activitats de reforç i ampliació adaptades al ritme del grup.
