# 7. Recursos

- **Materials:** apunts i guies del professorat, enunciats, esquemes, conjunts de dades, bibliografia i documentació oficial.
- **Tecnològics:** ordinador amb Internet, Linux/Windows, MySQL o MariaDB, MySQL Workbench, PostgreSQL, MongoDB, VS Code, Git/GitHub i aula virtual Aules.
- **Organitzatius:** agrupaments flexibles, tutories, treball autònom pautat, parelles de programació i coordinació amb l'equip docent.

Bibliografia de referència: Silberschatz et al., *Fundamentos de bases de datos*; Batini et al., *Diseño conceptual de bases de datos*; Teorey, *Database Modeling and Design*, a més de la documentació oficial dels SGBD emprats.
