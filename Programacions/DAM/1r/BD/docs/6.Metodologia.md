# 6. Metodologia

La metodologia serà activa, pràctica i competencial, adaptada a la modalitat semipresencial:

- explicacions breus i demostracions guiades;
- resolució progressiva de casos i reptes pròxims a l'entorn professional;
- pràctiques individuals i col·laboratives de modelatge, SQL i administració bàsica;
- aprenentatge basat en projectes, amb una base de dades que evoluciona durant el curs;
- aula virtual per a materials, vídeos, lliuraments, retroacció i seguiment;
- activitats inicials, de consolidació, aprofundiment, repàs i síntesi.

Es fomentaran l'autonomia, el raonament conceptual, la documentació tècnica, el control de versions, la comunicació i la revisió entre iguals. La coordinació amb altres mòduls i amb l'empresa donarà context als casos d'ús i a les dades tractades.
