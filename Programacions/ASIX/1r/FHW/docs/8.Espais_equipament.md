# 8. Planificació de l'ús despais i equipaments

El mòdul de **Fonaments de Maquinari** es desenvoluparà principalment en una aula d'informàtica o taller equipat amb ordinadors, connexió a internet, components de maquinari i ferramentes de diagnòstic i manteniment.

## Consideracions respecte als espais

* L'espai haurà de facilitar el treball segur amb equips oberts, components, perifèrics i ferramentes.
* Es reservaran moments específics per a pràctiques de muntatge, comprovació, inventari i recuperació del sistema.
* Es respectaran les condicions de seguretat, ergonomia, il·luminació, ventilació, ordre i neteja.
* Es promourà la gestió adequada de residus i el compliment de les normes de prevenció de riscos laborals.
