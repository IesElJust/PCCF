# Contribució dels RA a les competències professionals

<!-- 
De la guía:
-->

Tenint com a referent màxim la globalitat de les competències professionals, personals i socials associades al cicle formatiu, programem de manera competencial, prenent els Resultats d'Aprenentatge (RA) com a eix central. Els continguts esdevenen mitjans per a desenvolupar aquestes competències, mentre que els Criteris d'Avaluació (CA) ens permeten mesurar-ne el grau d'assoliment.

Tant els RA com els CA es defineixen al Reial decret del títol i es contextualitzen dins del Projecte Curricular del Cicle Formatiu (PCCF). En aquest document es recull la taula següent, que mostra la contribució dels diferents mòduls a les competències professionals:

Veiem de manera explícita aquesta relació:


* **RA1. Planifica la creació duna interfície web valorant i aplicant especificacions de disseny.**

  Contribueix a la competència professional: *g) Desenvolupar interfícies en aplicacions web dacord amb un manual destil, utilitzant llenguatges de marques i estàndards web.*


* **RA2. Crea interfícies Web homogenis definint i aplicant estils.**

  Contribueix a les competències professionals:
  * *g) Desenvolupar interfícies en aplicacions web dacord amb un manual destil, utilitzant llenguatges de marques i estàndards web.*
  

* **RA3. Prepara fitxers multimèdia per a la Web, analitzant-ne les característiques i manejant eines especifiques.**

  Contribueix a la competència professional: *h) Desenvolupar components multimèdia per a la seva integració en aplicacions web, emprant eines específiques i seguint les especificacions establertes.*


* **RA4. Integra contingut multimèdia en documents web valorant-ne l'aportació i seleccionant adequadament els elements interactius.**

  Contribueix a la competència professional: *h) Desenvolupar components multimèdia per a la seva integració en aplicacions web, emprant eines específiques i seguint les especificacions establertes.*


* **RA5. Desenvolupa interfícies web accessibles, analitzant les pautes establertes i aplicant tècniques de verificació.**

  Contribueix a la competència professional: *i) Integrar components multimèdia a l'interfície d'una aplicació web, fent l'anàlisi d'interactivitat, accessibilitat i usabilitat de l'aplicació.*


* **RA6. Desenvolupa interfícies web amigables analitzant i aplicant les pautes d'usabilitat establertes.**

  Contribueix a la competència professional: *i) Integrar components multimèdia a l'interfície d'una aplicació web, fent l'anàlisi d'interactivitat, accessibilitat i usabilitat de l'aplicació.*
