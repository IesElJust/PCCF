## 4.2. Continguts

Tot i que els Resultats d'Aprenentatge (RA) i els Criteris d'Avaluació (CA) del mòdul són inalterables, els continguts del mòdul sí que són un element susceptible de modificar-se, ampliar-se o fins i tot obviar-se de manera justificada.

D'aquesta manera, els continguts poden adaptar-se al teixit productiu en què s'ubica el centre i a les tecnologies concretes de què es fa ús. 

{continguts}

Els continguts del mòdul 0612 Desenvolupament web en entorn client, segons el BOE-A-2023-13221, es relacionen a continuació:

### RA1: Analitza i utilitza les capacitats del llenguatge JavaScript

**Continguts:**
- Objectes del navegador (window, document, navigator).
- Model d'Objectes del Document (DOM).
- Mètodes i propietats del document.
- Objecte window: finestres i marcs.
- Cookies i alternatives (Web Storage API).
- Eines de desenvolupament del navegador.
- Esdeveniments i gestors.
- Variables, tipus de dades i operadors.
- Estructures de control i funcions.
- Programació orientada a objectes en JavaScript.
- Expressions regulars.

### RA2: Desenvolupa aplicacions web amb processament asíncron

**Continguts:**
- Tècniques de desenvolupament en client.
- AJAX i XMLHttpRequest.
- API Fetch.
- Peticions asíncrones.
- Creació dinàmica d'interfícies.
- Frameworks de desenvolupament web (jQuery, React, Vue, Angular).
- Components en temps real.
- Manipulació del DOM.
- Validació de formularis.
- Gestió d'errors.

### RA3: Desenvolupa aplicacions web amb continguts multimèdia

**Continguts:**
- Llibreries multimèdia per a la web.
- Reproducció d'àudio i vídeo.
- Canvas i gràfics.
- Animacions CSS i JavaScript.
- WebGL i gràfics 3D.
- Integració de biblioteques gràfiques.
- Formats multimèdia i optimització.

### RA4: Desenvolupa aplicacions web adaptatives

**Continguts:**
- Principis de disseny responsiu.
- Fulls d'estil dinàmics i alternatius.
- Layouts adaptats a diferents mides de pantalla.
- Unitats CSS (absolutes i relatives).
- Media queries.
- Frameworks de disseny responsiu (Bootstrap, Foundation).
- Adaptació a diferents dispositius.
- Optimització de rendiment.

### RA5: Executa procediments de seguretat en aplicacions web

**Continguts:**
- Principis de seguretat web.
- Vulnerabilitats comunes (XSS, CSRF, SQL Injection).
- Validació i sanejament d'entrades.
- Autenticació i autorització.
- Polítiques de seguretat (CSP, CORS).
- Certificats SSL/TLS.
- bones pràctiques de seguretat.

### RA6: Realitza el desplegament d'aplicacions web

**Continguts:**
- Entorns de desplegament.
- Servidors web i servidors d'aplicacions.
- Configuració d'entorns.
- Continuous Integration / Continuous Deployment (CI/CD).
- Contenidors (Docker).
- Serveis al núvol (AWS, Azure, Heroku).
- Documentació del desplegament.
- Gestió d'incidències.

### RA7: Verifica la qualitat d'aplicacions web

**Continguts:**
- Avaluació heurística d'usabilitat.
- Normativa WCAG (accessibilitat).
- Proves de rendiment (temps de càrrega, resposta).
- Optimització (minimització, compressió, caché).
- Proves de seguretat bàsiques.
- Documentació de resultats.
- Eines de testing automatitzat.
