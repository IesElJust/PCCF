# Contribució dels RA a les competències professionals

<!-- 
De la guía:
-->

Tenint com a referent màxim la globalitat de les competències professionals, personals i socials associades al cicle formatiu, programem de manera competencial, prenent els Resultats d'Aprenentatge (RA) com a eix central. Els continguts esdevenen mitjans per a desenvolupar aquestes competències, mentre que els Criteris d'Avaluació (CA) ens permeten mesurar-ne el grau d'assoliment.

Tant els RA com els CA es defineixen al Reial decret del títol i es contextualitzen dins del Projecte Curricular del Cicle Formatiu (PCCF). En aquest document es recull la taula següent, que mostra la contribució dels diferents mòduls a les competències professionals:

Veiem de manera explícita aquesta relació:

* **RA1. Analitza i utilitza les capacitats del llenguatge JavaScript i dels objectes predefinits del navegador per crear aplicacions web interactives.**

  Contribueix a la competència professional: *e) Desenvolupar aplicacions multiplataforma amb accés a bases de dades utilitzant llenguatges, llibreries i eines adequats a les especificacions.*


* **RA2. Desenvolupa aplicacions web que processen dades i generen informació en temps real, avaluant l'ús de frameworks.**

  Contribueix a les competències professionals:
  * *e) Desenvolupar aplicacions multiplataforma amb accés a bases de dades utilitzant llenguatges, llibreries i eines adequats a les especificacions.*
  * *h) Desenvolupar interfícies gràfiques d'usuari interactius i amb la usabilitat adequada, emprant components visuals estàndard o implementant components visuals específics.*


* **RA3. Desenvolupa aplicacions web que integrain continguts multimèdia, avaluant l'ús de llibreries.**

  Contribueix a la competència professional: *g) Integrar continguts gràfics i components multimèdia en aplicacions multiplataforma, emprant eines específiques i complint els requeriments establerts.*


* **RA4. Desenvolupa aplicacions web adaptatives que s'adapten a diferents dispositius, emprant frameworks de disseny responsiu.**

  Contribueix a la competència professional: *h) Desenvolupar interfícies gràfiques d'usuari interactius i amb la usabilitat adequada, emprant components visuals estàndard o implementant components visuals específics.*


* **RA5. Executa procediments per respondre a incidents de seguretat en aplicacions web, documentant el procés seguit.**

  Contribueix a la competència professional: *b) Aplicar tècniques i procediments relacionats amb la seguretat en sistemes, serveis i aplicacions, complint el pla de seguretat.*


* **RA6. Realitza el desplegament d'aplicacions web en diferents entorns, documentant el procés i les incidències.**

  Contribueix a la competència professional: *s) Desplegar i distribuir aplicacions en diferents àmbits d'implantació verificant-ne el comportament i realitzant les modificacions necessàries.*


* **RA7. Verifica la usabilitat, accessibilitat i rendiment d'aplicacions web, dissenyant i executant proves per identificar deficiències.**

  Contribueix a la competència professional: *r) Realitzar plans de proves verificant el funcionament dels components programari desenvolupats, segons les especificacions.*
