# 7. Recursos

Els recursos didàctics del mòdul inclouen:

- Aula-taller amb ordinadors individuals, xarxa local i accés a Internet.
- Servidor web, servidor d'aplicacions i entorns de desenvolupament per a programació en servidor.
- Sistemes gestors de bases de dades i ferramentes d'accés a dades.
- Frameworks de desenvolupament web en servidor i clients per al consum de serveis web.
- Aula Virtual Aules per a materials, lliuraments i comunicació.
- Documentació oficial de les tecnologies utilitzades i materials elaborats pel professorat.
