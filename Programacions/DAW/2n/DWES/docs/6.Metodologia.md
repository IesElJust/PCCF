# 6. Metodologia

La metodologia prioritzarà el desenvolupament per projectes, la resolució de problemes i el treball pràctic sobre aplicacions web en entorn servidor.

El document de referència estructura el mòdul en quatre blocs: introducció al desenvolupament web client/servidor, projecte portfolio amb patró MVC sense framework, projecte multicapa amb framework servidor i projecte basat en serveis REST coordinat amb el desenvolupament en entorn client.

S'utilitzaran estratègies d'activació, aprenentatge basat en problemes, aprenentatge cooperatiu, classe invertida, demostracions guiades i treball per projectes.
