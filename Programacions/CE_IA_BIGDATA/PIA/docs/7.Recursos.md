# 7. Recursos

## 7.1. Recursos materials

El material didàctic del mòdul pot resumir-se en el següent:

* **Apunts proporcionats pel professor** en format web.
* **Textos d'ampliació i enllaços** a articles i documentació oficial relacionats amb cada unitat.
* **Pràctiques i exercicis** per reforçar el que s'ha exposat als apunts.

Tot aquest material s'oferirà a través de l'aula virtual durant el desenvolupament de cada unitat.

## 7.2. Recursos tecnològics

El programari a utilitzar serà principalment lliure:

* **Sistema operatiu**: El propi de l'alumne. A l'aula fem servir Linux Mint, però l'alumne pot utilitzar qualsevol altre sistema operatiu, ja que tot el programari amb què treballarem és multiplataforma.

* **Editor de codi**: Visual Studio Code com a editor de referència. També es pot fer ús de PyCharm, Eclipse, IntelliJ o qualsevol altre editor/IDE.

* **Llenguatge de programació**: Python3

* **Framework per a aplicacions**: Flet (Flutter + Python3), per a aplicacions multiplataforma amb interfície d'usuari per a mòbil, web o escriptori.

* **Desenvolupament web**: Flask per a la part servidora.

* **Eines al núvol**: Azure, AWS, IBM Watson.

## 7.3. Eines web i col·laboratives

* **Portal Aules**: Com a aula virtual, i que articularà el funcionament del mòdul.

* **Github**: Per a projectes en grup, treballar amb sistemes de control de versions distribuïts.

* **Google Colab**: Jupyter Notebooks al núvol per treballar sense necessitat d'instal·lació local.

## 7.4. Recursos organitzatius

Les primeres setmanes seran d'introducció als conceptes necessaris, instal·lació i configuració d'un entorn de treball i assoliment de les competències bàsiques necessàries per començar un projecte. Una vegada comencem a definir i arrancar els projectes, es planificarà la formació de grups heterogenis i s'assignaran rols i coordinació de tasques dins de cada projecte.
